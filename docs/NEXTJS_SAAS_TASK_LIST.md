## 현재 상태

**미구현·현행 정비 범위 밖 제안**입니다. 기준선에는 `Console/`·Next.js 애플리케이션이 없고, [SRS](SRS.md)의 필수 기능이나 [현재 작업 목록](task_list.md)의 미완료 작업으로 취급하지 않습니다. 이전 38개 세부 태스크는 구현 순서가 확정되지 않은 구상이므로 다음 단계 후보로 통합합니다.

| 단계 후보 | 범위 | 선행 결정 |
|---|---|---|
| 콘솔 시제품 | 태스크 선택·입력 업로드·작업 상태·결과 다운로드 | 기존 API 계약으로 가능한 UX와 업로드 완료 방식 |
| 사용자·테넌트 | 인증·권한·자기 작업 조회·리소스 격리 | job 소유권·접근 제어를 API 3종과 워커 계약에 추가 |
| 운영 화면 | 목록·검색·필터·실패 재시도·사용량 | Redis TTL 이후 이력 저장 방식, API 확장 범위 |
| SaaS 운영 | 과금·플랜·쿼터·감사·배포 | 비용·제품 요구·운영 책임·보안 경계 |

현재 `task_catalog`는 name/description만 공개합니다. 실행 경로·default_timeout 노출, 인증 헤더, 작업 목록 API, 결제 연동은 새로운 계약 변경이며 이미 제공되는 기능이 아닙니다. 구현 전 컨셉·요구사항·SAD·API를 먼저 확정하고 추적성을 추가합니다.
